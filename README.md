# 🏔️ Manali Swing — Extreme Adventure Sport Website

> Live production website for an extreme adventure sports company in Manali, India.
> Built with HTML5, CSS3, and JavaScript — fully responsive and deployed at **[manaliswing.com](https://manaliswing.com)**

---

## 🌐 Live Site

**[https://manaliswing.com](https://manaliswing.com)**

---

## What It Is

A complete multi-page website for an extreme adventure sport activity business based in Manali, India. Covers everything from tour listings to safety information and customer enquiries.

---

## Pages

| Page | Purpose |
|---|---|
| `index.html` | Homepage — hero, highlights, CTA |
| `about.html` | Company story and team |
| `tour.html` | Tour packages and details |
| `100-jumpstyles.html` | Activity styles showcase |
| `enquiries.html` | Customer enquiry form |
| `safety.html` | Safety guidelines and standards |
| `privacy.html` | Privacy policy |
| `terms.html` | Terms and conditions |
